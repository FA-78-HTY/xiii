# XIII

하고 싶은 일을 고르면, 상황별로 어떤 AI를 쓰면 좋은지와 바로 복사해 쓸 프롬프트를 알려주는 안내 사이트예요.

**사이트**: https://fa-78-hty.github.io/xiii/
**현재 버전**: v1.3 (2026-10-11) · [업데이트 기록 보기](CHANGELOG.md)

## 할 수 있는 것

- 글쓰기, 공부, 코딩, 영상 등 12가지 상황별 추천 AI
- 여러 AI를 이어 쓰는 추천 사용순서
- 빈칸만 채우면 완성되는 복사용 프롬프트
- 내가 주로 쓰는 AI 기준 안내

## 업데이트 방식

- 매달 1일 AI 도구 변화를 자동 점검해서, 바꿀 내용이 있으면 변경 제안(Pull Request)으로 올려요. 확인 후 Merge해야 사이트에 반영돼요.
- 올릴 때마다 커밋 설명에 버전과 바뀐 내용을 적고, [CHANGELOG.md](CHANGELOG.md)에 기록해요.
